================================================================================
FUNCTIONS IMPLEMENTED
================================================================================

1. getRankingBadge(ranking)
   Maps ranking to emoji badge: 1→🥇 2→🥈 3→🥉 n→n.

2. getSelectionBadgeStatus(status)
   Standardizes selection status (TR, BÖLGE, BARAJ_YOK)

3. filterAthletesBySearch(athletes, query)
   Case-insensitive name filtering with Turkish character support

4. renderAthletes(athletes, searchQuery)
   Main rendering function:
   - Sorts by display_top3 score
   - Generates DIV-based rows
   - Computes rankings
   - Attaches event listeners
   - Updates statistics
   - Responsive grid layout

5. populateDetailContent(contentDiv, athlete)
   Populates detail row with:
   - Personal info (age, gender, region, city, club)
   - Selection status with color coding
   - Tiebreaker calculations (Top3-6)
   - Event table with points and times

6. toggleDetailRow(athleteName)
   Toggles detail row visibility:
   - Shows/hides content
   - Auto-populates on first open
   - Rotates expand button

7. loadRankings()
   Async function that:
   - Reads filter values
   - Builds API query
   - Fetches /api/ranking
   - Stores data in window.athletesData
   - Renders athletes

  "display_top3": Float,

  "selected_slot": String,
  "multinations": Boolean
}
