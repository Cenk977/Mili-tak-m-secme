ISSUE #2: BADGE COLORS OVERRIDE (CRITICAL)
================================================================================

Location: panel/index.html, lines 860-861

Problem:
--------
Inline style attributes were overriding CSS class selectors with WRONG colors:

Wrong Colors (Inline Styles):
  - TR: #fff59d (yellow) ❌
  - BÖLGE: #c5e1a5 (green) ❌

Correct Colors (CSS Variables):
  - TR: #4a9eff (blue) ✓
  - BÖLGE: #ff9800 (orange) ✓
  - MULTINATIONS: #9c27b0 (purple) ✓

Before:
    <span class="selection-badge" data-status="${status}"
          style="background: ${status === 'TR' ? '#fff59d' : status === 'BÖLGE' ? '#c5e1a5' : '#f0f0f0'};
                 padding: 4px 8px; border-radius: 4px; font-weight: 600;
                 color: ${status === 'TR' ? '#f57f17' : status === 'BÖLGE' ? '#558b2f' : '#666'};">

After:
    <span class="selection-badge" data-status="${badgeStatus}">
        ${athlete.selected_slot || '-'}
    </span>

Impact: CRITICAL
- Badges displayed wrong colors to users
- Dark mode CSS variable overrides were bypassed
- CSS styling system completely undermined

Solution:
- Removed all inline styles
- Rely on CSS class selectors and variables
- Colors now properly theme with light/dark mode

Status: FIXED ✓
Commit: d36964b

ISSUE #3: MULTINATIONS BADGE COLOR (IMPORTANT)
================================================================================

Location: panel/index.html, line 841

Problem:
--------
Multinations athletes showed the star indicator (⭐) but the selection badge
didn't reflect multinations status. Badge would show TR/BÖLGE color instead
of purple, losing important visual distinction.

Before:
    const status = getSelectionBadgeStatus(athlete.selected);
    // ...
    <span class="selection-badge" data-status="${status}">

After:
    const badgeStatus = athlete.multinations ? 'MULTINATIONS' : (athlete.selected || 'BARAJ_YOK');
    // ...
    <span class="selection-badge" data-status="${badgeStatus}">

Impact: IMPORTANT
- Multinations athletes not visually distinguished
- Selection slot displayed but status unclear
- Users could miss important indicator

Solution:
- Check multinations flag FIRST in status logic
- Pass MULTINATIONS to data-status when applicable
- CSS selector now colors multinations badges purple

Status: FIXED ✓
Commit: d36964b
